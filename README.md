# КиноБилет — финальный проект по React

Full-stack приложение для бронирования билетов в кино.

- **Тема:** №4 — бронирование билетов в кино
- **Роли:** зритель и администратор
- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS, React Router, Redux Toolkit, TanStack Query, Axios, React Hook Form + Zod, Recharts, Sonner, lucide-react, dayjs
- **Бэкенд:** Django, Django REST Framework, SimpleJWT, SQLite

## Структура

```
frontend/   # React SPA
backend/    # Django REST API
docs/       # задание и материалы
```

## Запуск

Инструкции появятся после настройки фронтенда и бэкенда.
